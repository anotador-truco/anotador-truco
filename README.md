# Anotador de Truco

Aplicación web instalable (PWA), sin backend ni dependencias.

- Dos equipos o tres jugadores.
- Partidas a 15 o 30, con malas y buenas y fósforos de a cinco.
- Nombres editables, deshacer y contador de partidas ganadas.
- Tema claro u oscuro, guardado local y funcionamiento sin conexión tras la primera carga.

## Uso local

Ejecutar `python3 -m http.server 8000` en esta carpeta y abrir http://localhost:8000.

## Publicación

Servir estos archivos mediante HTTPS. Para GitHub Pages, seleccionar la rama `main` y la carpeta raíz en Settings → Pages (requiere disponibilidad de Pages para el repositorio).

En Android, abrir la web en Chrome y elegir Instalar app o Agregar a pantalla de inicio. Cada dispositivo guarda su marcador independientemente.
